# 回声心语 EchoMind

一个基于 GitHub Issue 的心理倾诉与 AI 自动抚慰项目。

写下你的心事，AI 倾听者会温柔地回复你。

## 使用方式

1. 先给本仓库点一个 ⭐ Star（原因见下方）
2. 打开 Issues → New issue，选择「我要倾诉」模板
3. 写下此刻的心事，提交 —— `倾诉` 标签会自动加上，你不用手动点任何东西
4. AI 倾听者会自动回复一段温暖的抚慰文字
5. Issue 会被锁定，保护这个空间不被干扰

> 提醒：这里不是私聊。Issue 是公开内容，锁定只是关闭跟帖、并不隐藏内容。如果不想让心事和你的主账号关联，建议开一个小号来写。

## 关于这个 Star

回声心语是一个人自掏 token 维护的公益项目——每一条倾诉的回复，都是真金白银的模型调用。

Star 是这里唯一的“供电方式”：它不花钱，却能让我们知道这个角落还有人在用，也让更多需要倾诉的人有机会看见它。

**所以，在留下你的心事之前，请先点一下右上角的 Star。**

> 说明：Star 前置校验目前按“请先手动点亮”执行，自动化脚本马上就会补上。在这之前，也请不要跳过这一步。

## 历史引用

如果你想在新的倾诉中提到以前的内容，可以使用 `[引用:#数字]` 格式：

```
我最近又遇到类似的事了...

[引用:#5]
```

AI 会把你引用的那条历史倾诉一起读进来。只支持引用你自己的记录——引用别人的编号会被自动忽略，那是属于他们自己的空间。

## 关于

回声心语（EchoMind）是一个公益项目，希望为需要倾诉的人提供一个安静的空间。

这里不评判、不催促、不灌鸡汤，只是听你说完。
