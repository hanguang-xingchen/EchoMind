# HanTing（含听）

一个基于 GitHub Issue 的心理倾诉与 AI 自动抚慰项目。

## 使用方式

1. 创建一个 Issue，写下你想倾诉的内容
2. 协作者为 Issue 添加 `倾诉` 标签
3. AI 倾听者会自动回复一段温暖的抚慰文字
4. Issue 会被锁定，保护这个空间不被干扰

## 历史引用

如果你想在新的倾诉中提到以前的内容，可以使用 `[引用:#数字]` 格式：

```
我最近又遇到类似的事了...

[引用:#5]
```

AI 会同时参考你引用的历史倾诉和你最近的倾诉记录。

## 关于

HanTing（含听/倾听）是一个公益项目，希望为需要倾诉的人提供一个安静的空间。
